# AI Greener — Vision & Philosophy

## What is AI Greener?

AI Greener (aigreener.com) is a living laboratory where lightweight AI and web experiments grow. It serves three interconnected purposes:

1. **Portfolio** — A showcase of full-stack web development and AI prototyping capabilities, demonstrating mastery across diverse technologies from TensorFlow.js computer vision to OpenAI-powered assistants.
2. **Educational Lab** — Each micro-application is a self-contained experiment that teaches one concept well. Visitors can interact with real working demos — not mockups — of complex technologies made accessible.
3. **Tech Blog** — Long-form articles sharing insights on web development, AI integration, and modern frontend architecture.

## The Name: AI + Green + -er

The name AI Greener carries layered meaning:

- **Greener as growth** 🌱 — Like plants in a garden, experiments grow organically. New ideas sprout, take root, and bloom into working demonstrations. The project is never "finished" — it's always growing.
- **Greener as freshness** 🆕 — A fresher, more approachable take on AI. Complex technologies like real-time pose detection or retrieval-augmented generation are stripped of academic jargon and presented as tangible, interactive web apps.
- **Greener as lightweight** ⚡ — Built on Astro's Islands architecture, every experiment ships minimal JavaScript. Heavy AI libraries load only when needed. The greenest code is the code that doesn't ship.
- **-er as a person** 👤 — AI Greener is also an identity — someone who "greens" AI, who makes it lighter, fresher, and more accessible through craft and code.

## Core Principles

### 1. Grow, Don't Bloat
Every new experiment must justify its weight. We use dynamic imports for heavy libraries, Astro Islands for selective hydration, and a strict zero-bloat dependency policy. The project grows in capabilities, not in bundle size.

### 2. Make It Touchable
Abstract concepts become real when you can interact with them. Object detection runs in YOUR browser with YOUR webcam. Currency charts render with REAL data from national bank APIs. AI assistants respond to YOUR questions. No screenshots — live demos.

### 3. One Island, One Lesson
Each micro-app is a focused experiment that demonstrates a specific technology or pattern. A movie app teaches MobX + React Query. A bank dashboard teaches Context API + useReducer. Visitors learn by exploring, developers learn by reading the source.

### 4. Ship Less, Teach More
Astro's philosophy aligns perfectly with ours: ship HTML by default, JavaScript by exception. Blog posts are static MDX. The landing page hydrates components only when they scroll into view. The heaviest AI libraries load only when the user explicitly activates them.

## Target Audience

- **Potential clients & collaborators** seeking evidence of full-stack and AI prototyping capabilities
- **Developers** exploring modern web patterns (Astro Islands, hybrid SSG/SSR, serverless AI endpoints)
- **Learners** wanting interactive, working examples of technologies they're studying
